## 运行与安全边界

数据库持久队列每分钟由受密钥保护的 Cron 驱动，最多 4 次退避重试。私有附件受账号所有权校验；删除或上传中断的对象由持久清理队列回收。模型密钥仅服务端使用。所有公开数据表启用 RLS。

文件上传单个 3 MB；原稿正文 50 万字符；手动备份最多 500 条收藏、1000 来源、1000 派生版本、100 个附件/6 MB 附件、总体 10 MB，超限明确报错。这不是自动异地灾备。

Supabase advisor 的四个 authenticated SECURITY DEFINER 提示已人工审查：创建记录、确认分析、消耗配额与重试函数有固定 search_path、auth.uid() 校验和跨账号测试。只供服务端使用的配置、配额和对象清理表默认拒绝客户端访问。OAuth 登录项目仍有未开启泄露密码保护的提示，未将其描述成零告警。
