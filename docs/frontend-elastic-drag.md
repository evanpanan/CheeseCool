# WorkBuddy 力场拖拽验收

按用户反馈替换上一版固定权重与归位弹簧。采用上传参考相同的 D3 forceLink(145)、forceManyBody(-480)、forceCenter、forceCollide(radius+26, iterations=2) 和默认速度衰减 0.4；拖动时 alphaTarget=0.3，释放后 alphaTarget=0，解除 fx/fy。没有回到各节点初始坐标的额外锚点力。

引擎回归直接建立参考 D3 模型，比较拖动 60 步、释放后 180 步的所有节点坐标，误差小于 1e-8；验证自然平衡而非强制归零。还覆盖 30/60/120 Hz、暂停、数据更新时保持抓取、删除端点、手动放置与实际内嵌打包产物。源码哈希校验防止引擎与内嵌代码不同步。

实际 React + sandbox iframe 的 Chromium 检查：点击不启动力场、鼠标拖拽、自然冷却与稳定、元数据更新不打断抓取、暂停手动拖动、失焦释放、手机单指拖动转双指缩放、减少动态偏好与零运行时异常。由于中心力和斥力，远处节点也可能受影响；这是本次参考手感的一部分，不再承诺断开节点完全静止或一秒回原位。

后端 V1 的冻结范围、数据与两个配置后验收项不变。
