# 图谱弹性拖拽验收

在既有发光节点与布局上添加有限范围的弹性位移；真实连线决定一跳、二跳及三跳影响，权重依次减弱，断开的节点不受牵引。恢复只作用于临时偏移，不重排布局或改变知识关联。

共享引擎自动回归覆盖 30/60/120 Hz、分层响应、断开节点稳定、小幅过冲及收敛、暂停、异常指针输入、更新期间保持抓取、删除节点及取消抓取。

真实 Chromium 使用实际 React + sandbox iframe，通过鼠标点击与拖拽、间接联动、释放后收敛、后台更新、暂停手动拖动、失焦释放、手机触摸拖动切换双指缩放、减少动态偏好和零运行时异常检查。合成场景拖拽时位移：根节点约 104.35，一跳约 29.17，二跳约 7.81，断开节点 0（均为画布坐标），释放后临时偏移归零、原始锚点不变。

此为前端交互调整，后端 V1 收尾范围与配置阻塞项不变。
